A4 · X, Yaw and slip

A4 · X, Yaw and slip
Stage1 — per sensor, no association
InputLevelled two-dimensional twist; platform forward speed vc; yaw rate
Estimatesψj, px,j per sensor; one shared c
SolverHuber-weighted IRLS Gauss–Newton
Sample gateAt least 50 samples per channel after the planar gate
Caveatc is a nuisance parameter, not a vehicle property

The non-holonomic constraint says the rear-axle centre has no lateral velocity. Any lateral velocity a sensor measures during a turn is therefore its own longitudinal lever arm — which makes X and Yaw solvable from that sensor alone.

1 The constraint that does the work

A wheeled platform cannot slide sideways at the rear-axle centre. Under the nominal non-holonomic constraint vc,y = 0, and the lateral velocity seen at a sensor origin during a turn is produced entirely by the sensor's longitudinal offset.

(A4.1)vj,y = vc,y + ω px,j   ⟶   vj,y = ω px,j  (nominal NHC)No reference to any other sensor appears. This is why X and yaw belong to the association-free group.

The sensor's own measurement is expressed in its own frame, so the unknown mounting yaw ψj appears as the rotation that brings that measurement onto the platform's lateral axis. Yaw and X are therefore estimated jointly from the same residual.

2 Relaxing the constraint for tire sideslip

Perfect no-slip does not hold in real driving. Lateral tire slip grows with lateral acceleration, so the rear-axle lateral velocity is approximated by a speed-and-rate dependent term with a single shared coefficient.

(A4.2)vc,y ≈ − c vc2 ωOne coefficient c is shared by all sensors, because it describes the platform rather than any individual mounting. Setting c = 0 recovers the classical non-holonomic constraint exactly.
c absorbs odometry bias
Empirically the fitted c changes sign with the odometry front end and with the voxel size used by it. It is therefore treated as a nuisance parameter that absorbs a common odometry bias, not as a physical vehicle characteristic. Its main victim is absolute X; relative X is protected because the bias is common-mode. Physical interpretation of c is not claimed.

3 Residual and unknowns

(A4.3)rj,k = sinψj ṵx,j,k + cosψj ṵy,j,k − ωj,k px,j + vc,j,k tan( c vc,j,k ωj,k )Per-sample lateral residual for sensor j. The first two terms rotate the levelled sensor velocity into platform axes, the third is the lever-arm term, the fourth is the slip correction.
(A4.4)θ = [ ψ1, px,1, …, ψJ, px,J, c ]⊤Arrow-shaped parameter vector: two parameters per sensor plus one coupling scalar. The normal equations are block-sparse and the shared coefficient can be eliminated by Schur complement.
Key point
The only cross-sensor coupling in Stage 1 is the shared c through the platform speed channel. With c fixed at zero the sensors decouple completely.

4 Robust solver

Slip significance is reported as the chi-square improvement of the fitted coefficient over the c = 0 model. The core computes the statistic and reports it; it does not apply a pass or fail threshold.

5 Sample gate

Before fitting, samples pass a planar-excitation gate. Its purpose is to keep only samples where the lever-arm term is actually excited and the inputs are mutually valid.

  • Sensor timestamp lies inside the platform-speed time range.
  • Selected yaw rate magnitude is at least the excitation floor (default 15 deg/s).
  • Platform forward speed magnitude is at least 1.0 m/s.
  • Levelled sensor yaw rate stays below the sanity bound (default 60 deg/s).
  • The sample lies inside an accepted turn segment from A1.
Caution
Fewer than 50 surviving samples drops the channel at stage planar. This is the most common drop in practice for sequences with little turning.

6 Timing behaviour

When the yaw rate in (A4.3) is the sensor's own, a clock shift applied to any other sensor does not change a single input of this estimator. Roll, pitch, yaw and X are then exactly invariant to inter-sensor time offsets — a measured, not merely argued, property.

The substitution that costs this property
If a sensor cannot estimate its own angular rate and a platform yaw-rate signal is substituted, the estimator becomes sensitive to the offset between that sensor and the platform clock, and X loses its synchronization-free status. The substitution remains useful for sensors that cannot produce geometric odometry at all, but it is a documented limitation rather than part of the main claim.
