Read this first
Every comparison on this page is descriptive. There are no independent repeated runs, so a smaller number is a smaller number on one configuration — not a claim of statistical superiority. Both baselines are our own reproductions, because no compatible official implementation was available for every dataset and input format.

1 How the numbers are computed

The estimator produces one final calibration per target sensor against one reference sensor, so the score is taken on those final sensor states. Averaging all directed pair permutations would count the same estimate several times and is not used.

1

Anchor Stage 1 to the reference pose

The estimated reference-to-target transform is composed with the ground-truth pose of the reference sensor. This is the only place ground truth enters, and it fixes the common frame so that a relative estimate can be compared against an absolute table.

2

Take X and rotation errors in that frame

The X error is the difference of the longitudinal component. The rotation error is the residual rotation between estimate and ground truth, read out as ZYX Euler Roll, Pitch and Yaw.

3

Take Y from the graph node, not from an edge

Relative Y is scored from the final graph node against the ground-truth lateral difference of the target and the reference. A single pairwise edge is not scored, because a single edge is not what the method outputs.

4

Average absolute errors over targets

The mean absolute error runs over all sensors except the reference. The reference contributes a structural zero and is excluded, leaving four targets for A2D2 and three for RadarScenes and Ford.

(M1)MAEd = (1 / (|S| − 1)) · Σj ≠ r |ed,j|for each degree of freedom d, over target sensors j, with reference r excluded
Note
Baselines are scored from their own reference-to-target outputs with the same anchor and the same protocol. The NH-Calib graph post-processing is not applied to them — that would hand our smoothing to a competitor's raw output and make the row uninterpretable.

2 Reference-relative five-DoF error

Reading the table

  • A2D2 — NH-Calib is smallest in X and Y. The registration row is not comparable: it covers only three accepted targets instead of four, and its X and Y errors are above one metre.
  • RadarScenes — NH-Calib is smallest in Y and Yaw; hand-eye SE(2) is smaller in X. Registration produces 843 mm in X, 1825 mm in Y and 112° in Yaw, which is a complete failure under the tested condition, not a usable calibration.
  • Ford Log4 — registration is smallest in X, Y, Roll and Pitch; hand-eye gives the smallest Yaw. This is the expected outcome on four overlapping 360° LiDARs and is reported as such.
  • Ford Log5 — NH-Calib is smallest in X and Yaw; hand-eye in Y, Roll and Pitch.
  • Ford Log6 — NH-Calib is smallest in Y; hand-eye in X and Yaw; registration in Roll and Pitch.
Key point
The pattern, not the minima, is the result: NH-Calib stays within the same order of magnitude as overlap-based registration where overlap exists, and remains usable where registration collapses. On Ford — the layout that favours registration — it does not win, and the manuscript says so.

3 Why registration wins on Ford and fails elsewhere

This is a qualitative explanation of an input condition, not a numerical overlap metric. No overlap number is introduced, because introducing one and then optimising against it would make the comparison circular.

4 Sample basis for the Ford relative-Y rows

Relative Y is regressed over common turning windows, so the number of accepted windows is the effective sample size behind each Y cell.

5 Ablation: clock offset

A constant offset was injected into the timestamps of one A2D2 channel and the whole estimation pipeline was rerun. The experiment separates a change in inter-sensor relative time from a change in relative time against the external CAN signal.

  • Under an inter-sensor-only offset, Roll, Pitch, Yaw and X are numerically unchanged, because their sample sets are unchanged. This is an implementation sanity check of the structural decomposition — not independent empirical evidence for it, and it does not extend to arbitrary jitter.
  • Against a frame-wise regression serving the same purpose, the common-window sum form gives 2.9–5.5× lower relative-Y error at the tested nonzero offsets.
  • In a separate per-degree-of-freedom hand-eye experiment, Roll, Pitch, Yaw, X and Y all responded to the offset — evidence that interval-level correspondence does not by itself decouple the estimated quantities.
  • No result showed the sample-wise control to be uniformly more sensitive than hand-eye, so timing sensitivity is not ranked by correspondence granularity alone.
Note
The sample-wise relative-Y control is the frame-wise counterpart of the sum-form estimator, not a separate calibration method, and is therefore not a row in the main table. On A2D2 its all-pair relative-Y error is 1785.10 mm, dominated by SIDE_LEFT; that failure is attributed to instantaneous odometry inconsistency rather than timing granularity alone. See B2 · Sum-form relative Y.

6 Ablation: ground-truth attitude injection

A small attitude error perturbs a projected velocity through a first-order cross-axis term, while the cosine scaling of the intended component is only second order. If Stage-1 attitude error were the dominant source of Stage-2 Y error, replacing attitude with ground truth should visibly improve Y. Stage 1 was rerun with ground-truth Roll and Pitch, and Stage 2 additionally with ground-truth Yaw. All variants reuse the common windows detected by the ground-truth-free baseline, so segment reselection cannot explain the comparison.

Key point
There is no consistent improvement — four of six entries get slightly worse. That rejects Stage-1 attitude error as the dominant Stage-2 Y source, which is a negative result and is reported as one.

7 Ablation: slip coefficient

  • X moves by a factor of several across the three treatments, and no treatment wins on all datasets — zero c is best on A2D2, free c on Ford Log4, prior c on RadarScenes.
  • Relative Y barely moves in comparison, staying inside the ranges above.
  • The sweep exposes X–c confounding directly: the c–X correlation is 0.40–0.70 and the normal-matrix condition number is 5.0×103–2.2×104.
Caution
Because of that confounding, c is retained only as a nuisance correction. No claim is made that physical slip and the longitudinal offset are separated. Alternative representative-value estimators were tried and did not remove the residual, so M-estimation is retained. See A4 · X, Yaw and slip.

8 What these numbers do not establish

  • Z is not estimated. The vertical offset is unobservable under planar motion and does not appear in any table. A numerical variation of Z in a baseline is not treated as an error of an observable quantity.
  • No statistical claim. Single configuration, no independent repeated runs, no confidence intervals. Bold marks a minimum, nothing more.
  • Baselines are reproductions. They diagnose applicability per input condition; they do not establish a universal ranking of published methods.
  • Single-log numbers are single-log numbers. Ford Log4, Log5 and Log6 disagree with each other on which method wins which axis. Neither their minimum nor their pooled value represents Ford.
  • RadarScenes is an alternative-input result. Doppler plus CAN is not a sensor-only five-degree-of-freedom demonstration.
  • Open limits — planar and lateral-motion violations, c–X confounding, front-end bias, and external-input reference and timing error.
