A5 · Reference relativization

A5 · Reference relativization
Stage1 — final step
InputPer-sensor φ, θ, ψ, px
OutputReference-relative X, Yaw, Roll, Pitch
OperationTransform composition, not Euler-angle subtraction
CancelsPlatform-common bias bcommon to first order
GaugeReference sensor is the frame origin; yr = 0 in Stage 2

All sensors ride the same body over the same segments, so they share the same model error. Composing every estimate against one reference sensor cancels that shared error to first order — and defines the quantity that ground truth can actually score.

Contents
  • 1Why relativize
  • 2How it is computed
  • 3What relativization does not fix

1 Why relativize

Each Stage 1 estimate is stated with respect to a platform frame that the data defines only implicitly: the motion plane the vehicle happened to travel on, the speed signal the dataset happened to publish, the slip coefficient that absorbed whatever bias the odometry front end carried. Those are shared inputs, and their errors land on every sensor the same way.

(A5.1)q̂j = qj + bcommon + εj   ⇒   q̂j − q̂r = (qj − qr) + (εj − εr)The shared term disappears; only the genuinely per-sensor part survives. This is the formal reason relative accuracy is consistently better than absolute accuracy in the reported results.
Key point
This applies to all estimated components, not only lateral offset. Motions that violate the platform model — a road with cross-slope, a speed signal referenced to the wrong point, suspension attitude — act on every sensor at once and are therefore removed by the same mechanism. Absolute values can be slightly off while relative values stay accurate.

2 How it is computed

(A5.2)T̂rj = ( T̂Vr )−1 T̂Vj,     R̂rj = R̂Vr⊤ R̂VjRotations are composed as matrices. Subtracting Euler angles is not equivalent and introduces order-dependent error once two angles are non-small.
1

Choose the reference

One channel is designated the reference. It is also the gauge anchor used by A3 and the fixed node of the Stage 2 graph, so that all three gauge choices coincide.

2

Assemble per-sensor poses

Roll and pitch from A2, yaw and longitudinal offset from A4 form each sensor's estimated pose in the implicit platform frame. Lateral offset is still unknown at this point — it is Stage 2's output.

3

Compose

Apply (A5.2) to every sensor. Rotational parts are extracted from the composed rotation matrix; the longitudinal component is differenced in the reference frame.

4

Report

The output of Stage 1 is reference-relative X, Yaw, Roll and Pitch. Lateral offset joins later to complete the five-degree-of-freedom result.

3 What relativization does not fix

  • Errors that differ between sensors — a channel whose odometry tracking degraded, or one with a much weaker turn sample — survive by construction. They are the residual εj − εr.
  • A poor reference channel contaminates every pair, since its own error enters all of them with the same sign. Reference selection is a real design decision, not a labelling convention.
  • The cancellation is first order. A bias large enough for second-order terms to matter is not removed cleanly.
  • Vertical offset is not recovered by relativization. It is unobservable under planar motion for structural reasons, discussed in the observability page.
